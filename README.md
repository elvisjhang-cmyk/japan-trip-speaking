# 日本自由行・口說冒險（原型）

你是第一次去日本的旅客。每天早上選擇行程，在劇情裡**開口說日文**推進故事。

- 先選「想表達的意思」→ 遊戲教你怎麼說 → 用麥克風說出來（或打字）
- 回答不必一字不差，只要意思對就會通過；說法不夠自然時會提示更好的說法
- 說錯了 NPC 不會打叉，而是露出疑惑的反應，並多給一點提示
- 熟練度（★）越高，字幕和提示越少；★★ 以上的句子直接進入「自由開口」模式
- 聽過的 NPC 台詞第二次出現時**不顯示字幕**（可以按「再聽」「慢速」或手動打開字幕）
- 聽不懂時，在任何對話中說「もう一度お願いします」，對方會放慢速度再說一次

內容：2 天、6 個支線（便利商店、問路、拉麵店、咖啡廳、伴手禮、祭典），約 30 個旅遊句子。
在拉麵店答應結衣的邀請，Day 2 才會解鎖祭典支線。

## 怎麼玩

需要透過本機伺服器開啟（麥克風無法在 `file://` 下使用）：

```bash
cd ~/語言學習遊戲 && python3 -m http.server 8123
```

然後用 **Chrome** 打開 <http://localhost:8123>。

- 語音辨識使用瀏覽器內建的 Web Speech API。Chrome 會把聲音送到 Google 辨識，所以需要網路。
- Safari 部分支援，Firefox 不支援；不支援時會自動切換成打字模式。
- 打字模式可以輸入日文，也可以輸入羅馬拼音（例如 `kore o kudasai`）。
- 進度存在瀏覽器的 localStorage，標題畫面可以「從頭開始」。

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `js/data.js` | **語言內容**：句子、判斷規則、支線劇情（要改劇情或加內容只要改這裡） |
| `js/game.js` | 遊戲引擎：行程、劇情流程、玩家回合、熟練度、畫面 |
| `js/judge.js` | 判斷玩家說的話符合哪個意思（關鍵詞比對＋羅馬拼音／假名統一） |
| `js/speech.js` | 語音朗讀（NPC）與語音辨識（玩家） |
| `css/style.css` | 樣式（支援手機與深色模式） |

### 新增一個支線

在 `data.js` 的 `QUESTS` 加一個物件即可，節點格式寫在檔案的註解裡。
新句子加到 `PHRASES`，`req` 寫「必須出現的關鍵詞組」，`bonus` 寫「有了會更自然」的詞，`neg` 寫「出現就代表相反意思」的詞。

### 做成其他語言

引擎跟語言無關。做英文版時，主要是換一份 `data.js`（英文句子與判斷規則），
再把 `speech.js` 的 `ja-JP` 改成 `en-US`，`judge.js` 的假名處理改成英文的大小寫與縮寫統一。

## 原型的限制與下一步

- **判斷方式**：目前用關鍵詞比對，免費也不用 API key，但無法理解完全沒預料到的說法。
  下一步可以把 `judge()` 換成 LLM（例如 Claude）判斷意思，介面不用改。
- **發音評分**：瀏覽器的語音辨識只判斷「聽不聽得懂」，不會給發音分數。
  需要的話可以接 Azure Pronunciation Assessment（有支援日文）。
- **語音品質**：NPC 用的是系統內建的日文語音。因為劇情是預先寫好的，正式版可以事先用高品質 TTS 生成音檔。
- **畫面**：角色先用 emoji 代替，之後可以換成插圖。
