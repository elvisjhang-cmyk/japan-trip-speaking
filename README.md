# 日本自由行・口說冒險（原型）

你是第一次去日本的旅客。像《美少女夢工場》一樣排行程、養數值，但數值只會因為你**真的開口說對日文**而成長。

**養成系統**

- 旅程 5 天 4 夜，每天分上午、下午、晚上（最後一天只有上午和下午），每個時段選一個地點，或回旅館休息
- 💴 旅費（¥30,000）和 ⚡ 體力有限：每個地點有花費和體力消耗，說錯也會累
- 五項數值：🛍️ 購物、🗺️ 問路、🍜 點餐、💬 聊天、👂 聽力。說對句子、答對聽力題才會上升，同一句說越多次成長越少
- 每個地點都有**數值門檻選項**：數值夠就能說更進階的日文、拿到獎勵（省錢、恢復體力、好感度），例如購物 20 以上才能在藥妝店問「免税できますか」
- 聽力不夠時會「聽不懂、錯過機會」，例如聽力 20 以上才聽得懂伴手禮店說可以試吃
- 早上和晚上會觸發事件（電車誤點、末班車、結衣的訊息），結果看數值
- 最後依數值和結衣的好感度決定結局，共 9 種；「再玩一輪」會保留學過的句子，可以收集不同結局
- 設計規劃見 [docs/養成系統規劃.md](docs/養成系統規劃.md)

**結衣的戀愛支線**

- Day 1 拉麵店認識 → Day 2 祭典 → Day 3 咖啡廳 → Day 4 居酒屋 → Day 5 車站告別，每一段要等到前一段的隔天才會開
- 💗 好感度 0～10：體貼的回答 +1，冷淡的回答 −1
- 結局：交到日本朋友（好感度 0～4）、約好再見面（5 以上）、告白成功（8 以上，而且聊天 50 以上說出「結衣さん、好きです」）

**口說**

- 先選「想表達的意思」→ 遊戲教你怎麼說 → 用麥克風說出來（或打字）
- 回答不必一字不差，只要意思對就會通過；說法不夠自然時會提示更好的說法
- 說錯了 NPC 不會打叉，而是露出疑惑的反應，並多給一點提示
- 熟練度（★）越高，字幕和提示越少；★★ 以上的句子直接進入「自由開口」模式
- 聽過的 NPC 台詞第二次出現時**不顯示字幕**（可以按「再聽」「慢速」或手動打開字幕）
- 聽不懂時，在任何對話中說「もう一度お願いします」，對方會放慢速度再說一次

**聽力訓練（聽懂店員在說什麼）**

- 第一次聽到店員用語時有字幕，並標出關鍵字（例如「温めますか＝要加熱嗎」）
- 之後再聽到同一類的話，會先問「對方剛剛說的是？」，答完才顯示字幕
- 價錢、路線這類一定要聽懂的內容，第一次就直接考（「一共多少錢？」）
- 不同店的店員會換一種說法問同一件事（例如「袋はご利用ですか」→「袋、お付けしますか」），練習聽懂真實的變化
- 聽力 ★★ 以上，店員會用接近真實的速度說話

內容：5 天 4 夜、11 個地點（便利商店、問路、拉麵店、咖啡廳、伴手禮、藥妝店、居酒屋，以及結衣的祭典、咖啡廳、居酒屋、車站告別），約 90 個句子。

## 怎麼玩

需要透過本機伺服器開啟（麥克風無法在 `file://` 下使用）：

```bash
cd ~/語言學習遊戲 && python3 -m http.server 8123
```

然後用 **Chrome** 打開 <http://localhost:8123>。

- 語音辨識使用瀏覽器內建的 Web Speech API。Chrome 會把聲音送到 Google 辨識，所以需要網路。
- Safari 部分支援，Firefox 不支援；不支援時會自動切換成打字模式。
- 打字模式可以輸入日文，也可以輸入羅馬拼音（例如 `kore o kudasai`）。
- 進度存在瀏覽器的 localStorage，標題畫面可以「從頭開始」。

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `js/data.js` | **語言內容**：句子、判斷規則、地點劇情、事件、結局、數值設定（要改劇情或加內容只要改這裡） |
| `js/game.js` | 遊戲引擎：時段與資源、劇情流程、玩家回合、熟練度與數值、事件、結局、畫面 |
| `js/judge.js` | 判斷玩家說的話符合哪個意思（關鍵詞比對＋羅馬拼音／假名統一） |
| `js/speech.js` | 語音朗讀（NPC）與語音辨識（玩家） |
| `css/style.css` | 樣式（支援手機與深色模式） |
| `assets/` | **圖片和影片**：角色立繪、背景、事件大圖。照 `assets/README.md` 的檔名放進來就會自動顯示 |

### 新增地點、事件、結局

- 地點：在 `data.js` 的 `QUESTS` 加一個物件，寫上開放時段 `times`、花費 `cost`、體力 `stamina`、對應數值 `skill`。節點格式寫在檔案的註解裡。
- 新句子加到 `PHRASES`：`req` 寫「必須出現的關鍵詞組」，`full` 寫「完整句子必備的詞組」，`neg` 寫「出現就代表相反意思」的詞。
- 事件加到 `EVENTS`，結局加到 `ENDINGS`（由上往下找第一個符合的）。

### 做成其他語言

引擎跟語言無關。做英文版時，主要是換一份 `data.js`（英文句子與判斷規則），
再把 `speech.js` 的 `ja-JP` 改成 `en-US`，`judge.js` 的假名處理改成英文的大小寫與縮寫統一。

## 原型的限制與下一步

- **判斷方式**：目前用關鍵詞比對，免費也不用 API key，但無法理解完全沒預料到的說法。
  下一步可以把 `judge()` 換成 LLM（例如 Claude）判斷意思，介面不用改。
- **發音評分**：瀏覽器的語音辨識只判斷「聽不聽得懂」，不會給發音分數。
  需要的話可以接 Azure Pronunciation Assessment（有支援日文）。
- **語音品質**：NPC 用的是系統內建的日文語音。因為劇情是預先寫好的，正式版可以事先用高品質 TTS 生成音檔。
- **畫面**：已經支援角色立繪（含表情）、背景圖和事件大圖／動態影片，放進 `assets/` 就會顯示；還沒放圖的地方用 emoji 代替。
