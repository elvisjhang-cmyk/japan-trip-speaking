## 二、店員和路人的立繪（9 個角色）

每個角色要做 **3 張**：`_normal`（平常）、`_smile`（玩家說對時）、`_confused`（玩家說錯時）。只做 `_normal` 也可以，其他兩張會先用它代替。

### 在 Grok 怎麼做

1. **第一張（_normal）**：上傳 `assets/yui_normal.png` 當畫風參考，再貼下面那個角色的整段提示詞。這樣畫風會跟結衣一致。
2. **另外兩張**：上傳剛做好的 `_normal`，貼這段，換掉最後的表情：

```
Same character, same outfit, same art style, same framing, plain pure white background. Change only the facial expression to: [表情]
```

| 檔名結尾 | `[表情]` 換成 |
|---|---|
| `_smile` | `big happy smile, eyes slightly closed` |
| `_confused` | `confused, head slightly tilted, puzzled look, one eyebrow raised` |

3. **去背**：Grok 沒辦法直接做透明背景。在 Mac 的 Finder 對圖片按右鍵 →「快速動作」→「移除背景」，就會得到透明的 PNG。
4. **存檔**：照下面的檔名放進 `assets/`，例如 `npc_konbini_normal.png`、`npc_konbini_smile.png`、`npc_konbini_confused.png`。
