# 養成系統規劃（參考《美少女夢工場》）

> 狀態：「原型範圍」已實作（3 天、8 個地點、3 個事件、7 種結局）。起始旅費改成 ¥20,000，讓 3 天的花費有取捨。

## 一句話

把「排行程 → 數值成長 → 看數值觸發事件 → 多重結局」的養成架構套進日本自由行，
但**數值只會因為真的開口說對而上升**。排行程是策略，開口是執行。

## 跟現在的版本差在哪

| | 現在 | 養成版 |
|---|---|---|
| 一天 | 每天一組固定支線，想玩哪個就玩哪個 | 每天分**上午、下午、晚上**三個時段，每個時段排一個行程 |
| 資源 | 沒有 | **旅費**、**體力** |
| 能力 | 技能條只是顯示熟練度 | 技能條就是養成數值，會決定事件結果和結局 |
| 事件 | 只有「答應結衣」一個旗標 | 依數值、時段、天數觸發的隨機與固定事件 |
| 結局 | 一個 | 依數值組合與人際關係，有多種結局 |
| 長度 | 2 天 | 7 天（原型先做 3 天） |

## 核心迴圈

```
早上在旅館排今天三個時段
  → 依序進入每個行程（劇情＋開口）
  → 說對多少，決定能力成長多少
  → 扣旅費、扣體力
  → 晚上回旅館：結算、可能觸發事件
  → 隔天
旅程最後一天 → 結局
```

## 資源

### 💴 旅費

- 起始 ¥50,000，整趟旅程不會增加（沒有打工，比較像真的旅行）。
- 每個行程有花費：便利商店 ¥500、拉麵 ¥1,000、伴手禮 ¥3,000、溫泉 ¥8,000、免費的散步和問路 ¥0。
- 說錯的代價可以是花錢：例如沒說「袋はいりません」就多付 ¥5 的袋子，沒聽懂「お会計は別々ですか」就幫朋友付了錢。小金額、有幽默感，但會讓玩家在意聽懂。
- 旅費太低時，貴的行程會鎖住，逼玩家選便宜但更需要開口的行程（問路、逛市場）。

### ⚡ 體力

- 每天 100，行程消耗 20～40，晚上回旅館恢復。
- 開口失敗多次會額外扣體力（「好累，講不出來」），讓玩家想在排行程前先練習。
- 體力低時可以選「在咖啡廳休息」：恢復體力，同時是一段輕鬆的聽力練習，不考口說。

這兩種資源讓排行程有**取捨**：想去溫泉就要先省錢，想一天跑三個地方就要夠熟練才不會累垮。

## 能力數值

沿用現在的五個技能，數值 0～100：

| 能力 | 來源 | 影響 |
|---|---|---|
| 🛍️ 購物 | 便利商店、伴手禮、藥妝店 | 殺價、退稅事件；結局「購物達人」 |
| 🗺️ 問路 | 車站、迷路事件 | 換車、錯過末班車事件 |
| 🍜 點餐 | 拉麵、居酒屋、咖啡廳 | 隱藏菜單、跟老闆聊天 |
| 💬 聊天 | 結衣、旅館老闆、攤販 | 交朋友、人際結局 |
| 👂 聽力 | 所有 NPC 台詞的聽力題 | 聽懂廣播、店員的變化說法 |

**成長規則**：每句說對加數值，加多少看「這句有多難」和「是否用了完整句子」。
只說關鍵字（例如只說「抹茶」）只加一半。同一句重複練習的效益遞減，鼓勵去新地方。

## 事件

事件在晚上結算或行程中途觸發，條件寫在資料裡：

```js
{ id: 'last_train', when: { time: 'night', minDay: 3 }, need: { 問路: 40, 聽力: 30 },
  success: '你聽懂了廣播，換到最後一班電車。',
  fail:    '你沒聽懂「終電」，只好搭計程車回旅館（−¥6,000）。' }
```

想放進去的事件（先列，之後挑）：

- **電車誤點廣播**：聽力夠就能改搭別的線，不夠會遲到，錯過下一個行程。
- **藥妝店退稅**：購物夠高才會問到「免税できますか」，省下一筆錢。
- **拉麵老闆的隱藏菜單**：點餐＋聊天夠高才會被問「常連さん？」。
- **結衣的邀約**：聊天夠高，連續幾天會有新邀約，累積好感度。
- **下雨天**：戶外行程取消，要臨時用日文問室內景點。
- **弄丟東西**：去派出所說明遺失物品，綜合考驗。

事件是養成系統最好玩的地方，因為玩家會想「我的聽力是不是該先練到 30」。

## 結局

最後一天依數值和旗標決定，先規劃 6 種：

| 結局 | 條件（草案） |
|---|---|
| 🎎 交到日本朋友 | 聊天 ≥ 60，結衣好感 ≥ 3 |
| 🍜 美食達人 | 點餐 ≥ 70 |
| 🛍️ 購物達人 | 購物 ≥ 70 且旅費剩 ≥ ¥10,000 |
| 🚃 一個人走遍日本 | 問路 ≥ 60，聽力 ≥ 60 |
| 🌸 完美旅程 | 五項都 ≥ 50 |
| 😵 迷路大王 | 問路 < 20（不是壞結局，而是好笑的結局） |

結局畫面列出「這趟學會的句子」和「還沒去過的地方」，提示下一輪可以怎麼玩。

## 原型範圍（第一步）

先做最小可玩版本，確認「排行程有沒有比現在好玩」：

1. 3 天 × 3 個時段。
2. 加旅費、體力兩個資源，顯示在頂部。
3. 把現在的 6 個支線加上 2～3 個新地點（藥妝店、居酒屋、休息用的咖啡廳），變成可以重複去的行程。
4. 技能條改成數值，說對加分。
5. 先做 3 個事件、3 種結局。
6. 存檔格式加版本號，舊存檔直接重新開始。

## 需要先決定的事

- **旅程長度**：7 天比較像養成，但內容量大很多。原型先 3 天，看玩起來的感覺。
- **行程能不能重複去**：養成遊戲需要重複，但同一個劇情重複會無聊。建議同一個地點每次換一組對話（例如便利商店：買早餐、寄宅配、買雨傘）。
- **失敗的懲罰多重**：太輕沒有取捨，太重會讓人不敢開口。建議只扣小錢和體力，不會卡關。
- **要不要角色養成的感覺**：可以讓主角有外觀變化（例如結局時穿和服、拿滿伴手禮），增加完成感。
